# Absensi Kehadiran Outsourcing

Kabupaten Kotawaringin Timur · Pilot v2.0.0

Frontend statis untuk GitHub Pages. Publikasikan dari folder yang berisi `index.html`, `.nojekyll`, `sw.js`, `manifest.webmanifest`, `assets/`, `css/` dan `js/`. Sumber lengkap terbentuk setelah menyalin file patch ke checkout PWA yang sudah berjalan. Konfigurasi deployment berada di `js/config.js`.

## Penggunaan

- Masuk saat online. Izinkan lokasi dan kamera untuk presensi. Kunci GPS, selesaikan tiga tantangan, tinjau foto, lalu kirim. Lihat tanda terima dan keputusan melalui Riwayat atau Shift.
- Buka Izin untuk mengajukan izin rentang tanggal atau melaporkan insiden. Draf dapat disimpan offline. Tombol Kirim memasukkan permohonan ke antrean perangkat. Status TERKIRIM muncul sesudah server menerima pengajuan.
- Beranda menampilkan rekap harian dan menit keterlambatan pribadi. Verifikator dapat memilih bulan untuk melihat grafik pegawai dalam lingkup pilot. Keputusan izin dan insiden tersedia untuk verifikator yang telah ditunjuk.
- MODE UJI tampil pada bagian terpisah saat server mengizinkan akun. Buka Perbarui untuk membaca perubahan. Ringkasan harian dan grafik menggunakan transaksi resmi.
- Saat pembaruan versi, buka kembali PWA ketika online. Cache baru memuat shell dan ikon. Antrean, draf, preferensi, dan foto profil menggunakan penyimpanan perangkat yang sudah ada.

Panduan operator, migrasi, pemulihan, dan matriks pengujian terdapat di paket rilis v2.0.0.
